Projeto API

INOVACRED — Análise de Risco de Crédito

Na Fatec, participei da elaboração do projeto INOVACRED, um sistema criado para analistas de crédito.

Proposta

Conceder crédito para populações historicamente recusadas por grandes instituições financeiras, identificando onde reside o consumo reprimido e a capacidade real de pagamento sustentável.

Solução Desenvolvida

Aplicação desenvolvida em equipe para apoiar analistas de crédito na consulta e comparação de indicadores econômicos, históricos e taxas financeiras de forma organizada e visual.

Contribuições Pessoais

Atuei no desenvolvimento de uma função de identificação de vulnerabilidade financeira por estado para apoiar o direcionamento de crédito alternativo ou microcrédito. Para isso, estruturei um pipeline para coleta, tratamento, cálculo de indicadores e visualização de dados socioeconômicos e de crédito.
